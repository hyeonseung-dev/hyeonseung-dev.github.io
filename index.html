Notion 포트폴리오

맡은 일은 결과까지 책임지고, 꾸준히 끝까지 해내는 백엔드 개발자입니다. 7년간 육군 재정장교로 근무하며 연간 약 6,000건·580억 원 규모의 예산 집행과 회계 업무를 담당하며 정확성과 데이터 신뢰성을 관리했습니다. 개발자로 전환한 뒤에도 학업·자격 취득·교육·프로젝트를 중단 없이 이어왔고, Java·Spring 프로젝트에서는 결제·환불·정산, 동시성 제어, 성능 개선과 운영 안정성을 직접 검증했습니다.

자기소개

책임감과 성실함을 가장 큰 강점으로 가지고 있습니다. 맡은 문제를 단순히 기능 구현으로 끝내기보다 실제 결과까지 확인하는 편입니다. 프로젝트에서도 동시 요청, 서버 강제 종료, 부하 상황을 직접 재현해 데이터 정합성과 운영 안정성을 확인했습니다.

최종 프로젝트에서는 4인 팀의 팀장을 맡아 일정과 개발 과정을 관리하면서 결제·환불·정산과 AI 검수 기능을 직접 설계·구현했습니다. 문제가 생기면 기술부터 선택하기보다 원인을 확인하고, 필요한 방법을 적용한 뒤 결과를 수치로 검증하는 과정을 중요하게 생각합니다.

개발자로 진로를 정한 뒤 전역 약 2년 전부터 군 업무와 컴퓨터과학 학업을 병행했고, 컴퓨터과학 학위와 정보처리기사 자격을 취득했습니다. 전역 이후에도 공백 없이 Java·Spring 개발 교육과 프로젝트를 이어오며 새로운 분야에서도 꾸준히 결과를 만들어 왔습니다.

기술 스택

Java 17, Spring Boot, Spring Security, JPA, MySQL, Redis / Valkey, Kafka, Docker, AWS EC2, S3, GitHub Actions, PortOne, K6, JUnit
